# 🚀 SAP UI5 Filterable Table Example

This project demonstrates a filterable table built with SAP UI5. The table allows users to filter data dynamically based on various criteria, using Model-View-Controller (MVC) architecture. Fragments are used for reusable components like the filter bar and value help dialogs.

# Features
    ✨ Filterable Table: Users can dynamically filter table data based on several attributes.

    🔄 Reusable Fragments:

    NameValueHelp.fragment.xml: Value help for name-based selections.
    RangeValueHelp.fragment.xml: For range-based filtering.

    🌍 Responsive Design: The table is designed to be responsive and works well on both mobile and desktop views.

    📊 Model-View-Controller (MVC): A structured MVC architecture is used to separate logic, presentation, and data layers.

# 📦 How to Use

    1.Clone the repository:
        git clone https://github.com/frau-azadeh/sapTable.git

    2.Install dependencies using npm:
        npm install
    
    3.Start the local development server:
        ui5 serve

    4.Open the application in your browser: http://localhost:8080

# 🔧 Technologies Used

    SAP UI5: A powerful web framework for building enterprise-grade applications.

    JSON: Data is handled via JSON, such as the mountains.json file.

    JavaScript: Custom logic is implemented using JavaScript.

    XML Views: Views are built using XML for the UI.
